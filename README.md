## 🧩 计划实现的控制链路

```mermaid
flowchart LR
    A[期望左右轮速度] --> B[速度控制器 PID]
    B --> C[PWM 与方向控制]
    C --> D[电机驱动器]
    D --> E[左右直流电机]
    E --> F[AB 编码器]
    F --> G[定时器编码器接口与测速]
    G --> B
```

这是**目标架构**，不是当前已经完成的全部功能。预计采用 STM32F103、双路电机驱动、两路 AB 编码器和 FreeRTOS，具体引脚映射与硬件型号以实际采购器件及后续验证为准。

## 🚀 如何阅读与使用本仓库

1. 先阅读 [Git + GitHub 操作手册](docs/Git-GitHub-操作手册.md)，了解如何保存和上传版本。
2. 查阅当前 Keil 工程的 `User/`、`System/` 等源代码目录（以实际工程结构为准）。
3. 使用 [开发日志模板](docs/开发日志模板.md) 记录每个功能的**目的 → 接线/配置 → 代码 → 仿真 → 问题 → 结论**。
4. 后续新增电机、编码器和 PID 功能时，按模块提交 Git，并在这里更新开发状态。

## 📒 开发规范

- 一次提交尽量只包含一个可解释的功能或修复。
- 提交前运行 `git status` / `git diff --cached --stat`，检查是否混入无关文件。
- 不上传账号令牌、密码、个人笔记及无关工程。
- 不把“编译通过”当成“仿真通过”，也不把“仿真通过”当成“实物验证通过”。
- 建议提交说明：`feat: add motor PWM control`、`fix: correct encoder sign`、`docs: update PWM test notes`。
